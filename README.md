# Bilimanga-Downloader

[English](README.en.md) · **中文**

下载 [bilimanga.net](https://www.bilimanga.net/) 的漫画和 [哔哩轻小说](https://www.bilinovel.com) 的轻小说，按卷打包成 **EPUB** 或 **PDF**，方便在阅读器里看。

两种用法，任选其一：

- **🐵 油猴脚本版（免装 Python，推荐轻度使用）**：装个浏览器扩展就能用，在书页点一下即可下载。
  → [Greasy Fork 一键安装](https://greasyfork.org/zh-CN/scripts/588995-bilimanga-%E6%BC%AB%E7%94%BB-%E8%BD%BB%E5%B0%8F%E8%AF%B4%E4%B8%8B%E8%BD%BD%E5%99%A8)（详见 [`userscript/`](userscript/README.md)）
- **💻 命令行版（本页下方）**：纯 Python，适合批量下载、自动化。

## 快速开始

1. 到 [Releases](../../releases) 下载 `Bilimanga-Downloader-CLI.zip` 并解压。
2. 打开程序：
   - **macOS**：双击 `run.command`
   - **Windows**：双击 `run.bat`

   会弹出一个终端窗口，第一次打开时它会自动装好运行需要的东西（稍等一会儿）。
3. 在窗口里**粘贴一个漫画或轻小说的网址**，回车。例如：
   - 漫画：`https://www.bilimanga.net/detail/703.html`
   - 轻小说：`https://www.bilinovel.com/novel/2139.html`
4. 确认书名后，用**方向键 ↑↓ 移动、空格勾选**要下载的卷（也可以直接输入 `1-5,8` 这样的范围），回车。
5. 等它下完，文件就在你的**下载文件夹**（`~/Downloads`）里，按书名分好了目录。

下载完一本，窗口会回到起点，可以接着粘下一本；输入 `q` 退出。

> 需要装 **Python 3.9 以上**。如果双击没反应，见文末「双击打不开」。

## 界面怎么用

进入窗口后是一步步引导的，每一步下方都有提示：

- **粘贴网址**：漫画站还是轻小说站，程序按网址**自动识别**，不用你先选类型。也可以只输入书号（比如 `703`），这时会问你一次是漫画还是轻小说。
- **确认书籍**：显示书名、作者、卷数，回车确认，输入 `n` 退回重来。
- **选择要下的卷**：
  - 方式一：**光标勾选**——↑↓ 移动，空格选/取消，回车确认。
  - 方式二：**输入范围**——如 `1-9,15,20-25`（逗号隔开、`a-b` 表示连续区间），直接回车表示全选。
- **选格式**（仅漫画）：EPUB 或 PDF；轻小说固定 EPUB。
- 任意一步输入 `b` 都能**退回上一步**。

在起点输入 `s` 进设置、`c` 连接百度网盘、`q` 退出。

## 百度网盘（可选）

顶部会显示百度云状态：**未连接**时下载只能存本地；**已连接**则显示你的昵称，下载时可选「存本地 / 上传网盘」。

- 在起点输入 **`c`** → 弹出浏览器登录你的百度账号 → 登录成功后弹**桌面通知**「已连接」，登录态**长期保存**、每次启动自动检测。
- 下载时用**方向键**选择「☁ 百度网盘」即可上传，默认存到网盘 `/bilidownloader/漫画|小说/书名/`（可在设置里改根路径）。
- 在设置里可**断开账号**或改**上传根路径**。

> ⚠️ 百度上传走非官方接口（Cookie 方式），**违反百度网盘服务条款**、且百度改版可能使其失效；登录态（BDUSS）等于账号完整凭证、保存在本地，请勿外泄。仅供把自己下载的内容备份到自己的网盘。

## OneDrive（可选，走微软官方 API）

顶部会显示 OneDrive 状态；**已连接**后下载时可选「☁ OneDrive」，上传到你自己的
`OneDrive/bilidownloader/漫画|小说/书名/`。

- 在起点输入 **`o`** → 程序打开[配置教程](docs/onedrive.md)并给出一行「打开 `microsoft.com/devicelogin`
  输入验证码 XXXX」→ 你在浏览器登录**自己的微软账号**、点同意即可（**零注册，开箱即用**）。
- 登录态**长期保存**（自动续期），每次启动自动检测；设置里可**断开**或改**上传根路径**。
- 想要最稳可在设置里填**自己注册的 client_id**（免费 2 分钟，见[教程](docs/onedrive.md)），覆盖内置公共应用。

> OneDrive 走**官方 Graph API + OAuth2**（不是逆向接口），只授权“读写你自己的 OneDrive 文件”；
> 本地仅保存一个 `refresh_token`，请勿外泄。详见 **[docs/onedrive.md](docs/onedrive.md)**。

## 设置

在起点输入 `s` 进入设置，逐项按回车即可保留原值、输入新值即可修改，改完自动保存：

- **下载输出目录**：默认存到系统下载文件夹 `~/Downloads`；可以改成任意目录。
- **默认格式**：EPUB 或 PDF（只影响漫画）。
- **并发线程数**：下载的**起始线程数**与**上限线程数**（漫画自适应并发从起始数起步、最多到上限；轻小说正文为限流安全固定串行，此设置影响其插图并发）。
- **代理**：默认自动（跟随系统环境变量，连不上自动改直连）；也可以填 `http://127.0.0.1:7890` 强制走代理。
- **限速 / 失败重试 / 断点续传**：一般保持默认即可；断点续传开启后，重下同一本会跳过已下好的文件。
- **百度网盘**：上传根路径、断开账号。
- **调试日志**：排查问题时打开，会把详细日志写到 `logs/`。

## 下载说明

- 漫画和轻小说**默认都是直连下载**，速度快、也不占内存。只有当网站偶尔弹出人机验证时，才会**自动调用本机的 Chrome / Edge** 过一次验证，之后一直复用。所以建议装了 **Chrome 或 Edge** 备用，但平时基本用不到。
- 下载线程数会根据网络情况自动调节，遇到网站限流会自动放慢、稍后恢复，尽量下全不漏页。

## 命令行用法（进阶）

不想双击、想用命令行或做自动化的话，直接跑 `start.py` 即可（首次会自动创建项目内的 `.venv` 并装依赖，不影响系统环境）：

```bash
python3 start.py                              # 打开交互界面（同双击）
python3 start.py <网址或书号>                  # 跳过粘贴，直接进入这本的确认/选章
python3 start.py --out ~/Books <网址或书号>    # 本次下载存到指定目录
python3 start.py --debug                       # 开启调试日志
```

- `--out <目录>`：本次输出到指定目录，不写回设置（适合临时改存放位置）。
- `--debug`：输出详细日志，便于排查问题；除写入 `logs/` 外，还会在**下载目录**持续更新一份
  `log.txt`（每章正文、每张图、限流冷却、网盘上传都记下，卡住那一刻也在），把它发来即可定位问题。
- 网址支持详情页链接、目录页链接或纯书号三种写法。

## 双击打不开？

- **macOS** 首次打开若被系统拦截（“无法验证开发者”），到「系统设置 → 隐私与安全性」点「仍要打开」；或右键 `run.command` → 打开。
- 需要本机装有 **Python 3.9+**。终端里执行 `python3 --version` 能看到版本即可。
- Windows 的 `run.bat` 已经切到 UTF-8 编码，中文不会乱码。

## 目录结构

```
Bilimanga-Downloader/
├── start.py                    # 入口（首次运行自动建 .venv 装依赖）
├── run.command / run.bat       # macOS / Windows 双击启动
├── userscript/                 # 🐵 油猴脚本版
└── src/bilimanga_dl/
    ├── app.py                  # 编排：加载插件 → 进入界面
    ├── core/                   # 基础设施：网络/限流/日志/图片/插件注册表
    ├── sources/                # 内容源插件（漫画 / 轻小说，新站点=加一个文件）
    ├── packagers/              # 打包器插件（EPUB / PDF）
    ├── storage/                # 存储去向插件（本地 / 百度网盘…）
    └── ui/                     # 终端交互（步骤机、选章、设置）
```

> 插件化：加新站点/新格式/新云盘 = 新增一个插件文件并注册，无需改动其它层。
